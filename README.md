## ✨ Что нового в версии v0.6
* Обновлённый 3D-мир с генерацией рельефа и деревьев.
* Расширенный выбор блоков в инвентаре и удобный хотбар.
* Поддержка управления как с клавиатуры и мыши (ПК), так и с сенсорного экрана (смартфоны).
* Оптимизированная работа прямо в браузере через GitHub Pages.

## 🎮 Управление

### На ПК (Клавиатура и мышь)
* **`W` / `A` / `S` / `D`** — движение
* **Мышь** — обзор камерой
* **`Пробел` (Space)** — прыжок
* **ЛКМ (Левая кнопка мыши)** — сломать блок
* **ПКМ (Правая кнопка мыши)** — поставить блок
* **`1` – `8` / Колёсико мыши** — выбор блока в хотбаре

### На смартфоне (Сенсорный экран)
* **Свайп по экрану** — поворот камеры
* **Экранные кнопки движения и прыжка** — передвижение по миру
* **Кнопки действия** — разрушение и установка блоков
* **Нажатие по слоту внизу** — переключение выбранного блока
