# MiniCraft0642 (v0.5)

Браузерная 3D-песочница на чистом HTML5 Canvas и JavaScript для смартфонов и ПК.

🎮 **Играть онлайн:** https://github.io

## Что нового в v0.5
- **Несколько слотов сохранения миров**: создавай, переключайся и удаляй отдельные миры со своими настройками, названием и инвентарём.
- **Верстак и система крафта**: перерабатывай добытый дуб в доски, создавай верстак, каменный меч, кирпич, стекло и динамит (TNT).
- **Пиксельные текстуры блоков**: процедурная пиксельная детализация граней для травы, земли, камня, песка, дерева, досок, верстака, листвы, кирпича и TNT.
- **Улучшенная боевая система**: атака мобов простым нажатием по экрану и исправленный ближний бой с зомби.

## Основные возможности
- **Режимы игры**: Выживание (здоровье, голод, сбор блоков, яблоки, ночные зомби) и Креатив (полёт и бесконечные блоки).
- **Генерация миров**: 3 типа ландшафта (Холмы, Плоский, Остров) и 3 размера карты.
- **3 вида камеры и Редактор скинов**: 1-е, 2-е и 3-е лицо, настройка цветов персонажа и импорт `.png` скинов.
- **Кроссплатформенное управление**: сенсорная крестовина (PE-стиль) для телефонов + клавиатура и мышь с переназначением клавиш для ПК.
- **Звук и языки**: встроенные 8-битные звуки (Web Audio API) и переключение между русским и английским языками.  Также сегодня 21 ноября я сделал версию для  телефонов с поддержкой J2me вот ссылка https://github.com/olegvideo-player/Minicraft0642-J2me-
